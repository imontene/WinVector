# Corpus de SVG de referencia

Archivos SVG que WinVector debe abrir, mostrar y guardar sin dañarlos. Las pruebas de ida y vuelta y de fidelidad visual los recorren todos.

## Cómo añadir un archivo

- Usa archivos pequeños que muestren un caso concreto. Pon el caso en el nombre: `degradado-radial-con-foco.svg`, `trazado-arcos-relativos.svg`.
- Agrúpalos por carpeta según el área: `formas/`, `trazados/`, `texto/`, `degradados/`, `ajenos/` (exportados por otras aplicaciones).
- Solo archivos que puedas compartir bajo la licencia del proyecto. Para archivos de terceros, indica el origen y la licencia en `FUENTES.md` dentro de su carpeta.
- Sin scripts ni referencias a recursos externos, salvo que el archivo pruebe precisamente cómo se bloquean.
